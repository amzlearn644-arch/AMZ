# AMZ — کاتالوگ نرم‌افزار

نسخهٔ محلی AMZ یک کاتالوگ سبک فارسی برای پیدا کردن نرم‌افزارهاست. برنامه با FastAPI و SQLite اجرا می‌شود، به فایل‌های نصب دست نمی‌زند و دانلود را مستقیماً به وب‌سایت منبع می‌سپارد.

## اجرا در ویندوز

1. Python 3.10 یا جدیدتر نصب باشد.
2. در PowerShell یا ترمینال VS Code، در همین پوشه اجرا کنید:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
   ```

3. سایت را در `http://127.0.0.1:8000` باز کنید.

در اجرای نخست، داده‌های نمونه داخل `data/amz.sqlite3` ساخته می‌شوند. برای استفادهٔ عادی به سرویس‌های خارجی نیاز نیست. همگام‌سازی متادیتا پس از بالا آمدن برنامه و سپس هر شش ساعت بررسی می‌شود؛ دادهٔ قبلی هنگام خطای یک منبع حفظ می‌شود.

## API محلی

- `GET /api/software?q=firefox&os=Windows` — جست‌وجو و فیلتر
- `GET /api/software-suggestions?q=fi` — پیشنهادهای سریع بر اساس ابتدای نام
- `GET /api/software/{slug}` — جزئیات نرم‌افزار
- `GET /api/sync-status` — آخرین وضعیت منابع
- `POST /api/sync` — اجرای دستی sync
- `GET /health` — بررسی سلامت

## پنل مدیریت

پنل مدیریت در `http://127.0.0.1:8000/admin` قرار دارد و به‌صورت پیش‌فرض خاموش است.

1. فایل `.env.example` را به `.env` کپی کنید (اگر قبلاً این کار را نکرده‌اید).
2. در `.env` یک رمز عبور قوی تنظیم کنید:

   ```
   AMZ_ADMIN_PASSWORD=یک-رمز-طولانی-و-یکتا
   ```

3. برنامه را دوباره اجرا کنید و وارد `/admin` شوید.

امکانات پنل: افزودن، ویرایش و حذف نرم‌افزار؛ جست‌وجو و صفحه‌بندی کاتالوگ؛ ثبت، ویرایش و حذف JSON API در «منابع API»؛ نگاشت مسیرهای پاسخ و فیلدهای نرم‌افزار؛ و اجرای دستی همگام‌سازی. نشست مدیر با یک کوکی امضاشده و HttpOnly تا ۱۲ ساعت فعال می‌ماند و با «خروج» بسته می‌شود. برای امنیت بیشتر، برنامه را فقط روی `127.0.0.1` اجرا کنید؛ پنل درخواست‌هایی را که Host آن‌ها loopback نیست رد می‌کند، درخواست‌های POST با Origin ناهماهنگ رد می‌شوند و صفحه‌های پنل با `Cache-Control: no-store` ارسال می‌شوند. پنل را پشت reverse proxy یا روی شبکهٔ عمومی منتشر نکنید.

نکته: عنوان‌های واردشده از یک منبع همگام‌سازی‌شده (مثل F-Droid) ممکن است در sync بعدی بازنویسی شوند؛ برای موارد دستی، منبع `AMZ` ثبت می‌شود. حذف یک مورد همگام‌سازی‌شده نیز فقط تا sync بعدی دوام دارد. هیچ فایل نصبی در پنل آپلود یا ذخیره نمی‌شود و لینک‌ها فقط HTTPS پذیرفته می‌شوند.

## منابع و افزودن Provider

- **F-Droid:** adapter برای خواندن metadata از index عمومی `https://f-droid.org/repo/index-v1.json` آماده است، اما به‌صورت پیش‌فرض غیرفعال است تا اجرای محلی بدون شبکه سریع باشد. فایل `.env.example` را به `.env` کپی کنید و سپس `AMZ_ENABLE_FDROID=1` را تنظیم کنید. تعداد موارد با `FDROID_MAX_ITEMS` (پیش‌فرض ۲۰۰) محدود است. URL برنامه از نام APK ثبت‌شده در index و دامنهٔ رسمی ساخته می‌شود.
- **EveryVersion:** feed عمومی `https://everyversion.net/api/v1/apps.json` از بخش «منابع API» قابل ثبت است؛ آرایه در `apps` قرار دارد و `slug` به‌عنوان شناسه استفاده می‌شود. این API برای هر برنامه صفحه و فایل JSON جزئیات می‌دهد، اما لزوماً لینک نصب مستقیم یا آیکن ارائه نمی‌کند؛ در چنین مواردی لینک صفحهٔ برنامه نمایش داده می‌شود و فایل نصب دریافت یا عبور داده نمی‌شود.
- **OpenUse:** فهرست عمومی برنامه‌ها از `https://api.openuse.app/v1/public/apps` خوانده می‌شود؛ پاسخ در `data` قرار دارد و با `offset`/`limit` صفحه‌بندی می‌شود (حداکثر ۱۰۰ رکورد در هر درخواست). در دیتابیس فعلی منبع OpenUse با ۳۸۱ رکورد همگام شده است. `url` هر رکورد صفحهٔ آن در OpenUse است و به‌عنوان مقصد دریافت/اطلاعات استفاده می‌شود، نه لینک مستقیم فایل نصب. این فهرست شامل انواع مختلفی از موارد (از جمله بازی و منابع) است؛ پس همهٔ موارد الزاماً نرم‌افزار دسکتاپ یا نصب‌شدنی نیستند. دامنهٔ جزئیات و محدودیت درخواست upstream را رعایت کنید.
- **Winget:** provider از پوشهٔ رسمی manifests در `https://api.github.com/repos/microsoft/winget-pkgs/contents/manifests` استفاده می‌کند. این endpoint فهرست کامل و تخت نیست؛ برای کم‌کردن درخواست‌ها، AMZ فقط ۱۰ package ID منتخب را با نهایتاً ۵۴ درخواست GitHub metadata در هر sync بررسی می‌کند. لینک‌ها به صفحهٔ package upstream هدایت می‌شوند؛ AMZ فایل YAML یا installer را میزبانی/عبور نمی‌دهد.
- feed باید آرایهٔ JSON یا شیئی مانند `{"items": [...]}` بدهد. هر مورد باید `id` و `name` داشته باشد. سایر فیلدها اختیاری‌اند. لینک‌های خارجی فقط HTTPS پذیرفته می‌شوند. فرم «منابع API» از Bearer token، مسیر فهرست، نگاشت مسیرهای تو‌در‌تو و صفحه‌بندی Offset/Limit با حداکثر ۲۰ صفحه در هر sync پشتیبانی می‌کند؛ توکن در دیتابیس محلی نگهداری می‌شود و در فرم ویرایش دوباره نمایش داده نمی‌شود.
- هر منبع جداگانه و با timeout محدود می‌شود. فایل‌های نصب/باینری دریافت نمی‌شوند. لینک دریافت در صفحات مستقیماً باز می‌شود و مسیر proxy برای فایل وجود ندارد. همگام‌سازی از دکمهٔ کنار هر API فقط همان منبع را اجرا می‌کند؛ دکمهٔ عمومی داشبورد همهٔ منابع را اجرا می‌کند.

### اجرای sync دستی

در ترمینال دیگر:

```powershell
Invoke-RestMethod -Method Post http://127.0.0.1:8000/api/sync
```

> endpoint دستی sync برای استفادهٔ محلی است و در صورت انتشار عمومی باید به دسترسی مدیر محدود شود.

## مصرف منابع و استقرار آینده

- یک process، یک loop زمان‌بندی سبک و SQLite؛ بدون صف، Redis، ORM یا دانلود فایل.
- SQLite فقط metadata را نگه می‌دارد. پوشهٔ `data/` در Git نادیده گرفته شده است.
- در حال حاضر برای loopback محلی طراحی شده، نه انتشار در شبکه یا اجرای چند worker. هاست مقصد باید پیش از استقرار بررسی شود: هاست‌های رایگان زیادی process پایتون پایدار یا فایل SQLite پایدار/قابل‌نوشتن ندارند. در چنین حالتی رابط استاتیک و sync زمان‌بندی‌شده به سرویس سازگار منتقل خواهد شد.
- آیکن‌ها فعلاً با نشان‌های سبک و محلی جایگزین شده‌اند تا برای نمایش کاتالوگ نیاز به واکشی تصاویر خارجی نباشد.
